# Changelog

## v0.9.0 - 2026-11-28

Canonical Agent Context Memory release.

- Restored **Agent Context Memory (ACM)** as the public specification name.
- Defined **Shared ACM** as a team use of ACM, not as a separate product or
  specification name.
- Updated the repository, illustration, citation, and Zenodo metadata to the
  canonical identity.
- Added release relationships to Augmented Individual Intelligence (AII),
  Principles of Earned Autonomy (PEA) v2.4.0, and Agent Evidence Proxy
  (AEP) v0.1.0.
- Preserved historical SACM titles, citations, and archives for versions 0.7.0
  through 0.8.0.

This release does not change any of the 21 numbered requirements, conformance
levels, implementation claims, or the Proposed status of the specification.
